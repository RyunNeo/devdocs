# CedarDesk API 与权限规范

这是原创虚构项目，仅用于 RAG 评测。

API 使用 HttpOnly Cookie 认证，会话有效期为 10 天；不是列表缓存时长。
未登录返回 401；访问不属于自己的私有变更返回 404；已登录但来源不受允许返回 403。
创建变更需要客户端提供 UUID 格式的 request_id。同一用户重复 request_id 返回 409，不重复创建。
每用户每分钟最多 18 次写请求，超出返回 429；此限制与每天 30 条变更配额不同。
批量发布必须逐条检查所有权与审批状态，单条失败不能使其他用户的变更被发布。
审计日志仅记录请求编号、操作类型、状态和耗时，不记录评论正文、Cookie 或密钥。
