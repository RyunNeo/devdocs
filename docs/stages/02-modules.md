### API

- POST /knowledge-bases：创建。
- GET /knowledge-bases：当前用户列表，带 limit/offset 分页。
- GET /knowledge-bases/{id}：当前用户的单个知识库。
- PATCH /knowledge-bases/{id}：修改名称或描述。
- DELETE /knowledge-bases/{id}：删除。

### 基础约定

- 名称去除首尾空格，展示保留内部空格；长度 1–80 字符。
- 描述可省略或为 null，文本最大 1000 字符。
- PATCH 只更新明确传入的字段；description=null 清空描述。
- 未登录返回 401；资源不存在或属于其他用户都返回 404。
- 资源所属用户由认证取得，不允许请求体指定 user_id。
- 用户更新规则：同一账号不允许重名，忽略大小写和所有空白字符。
  name 保存展示名称，name_key 保存去掉所有空白并 casefold 后的比较值；不同账号可以同名。
- 当前没有文档、向量和业务会话表，删除关联数据的验收在对应模块补齐。

## 删除流程集中验收

这一轮无新增环境变量、依赖或迁移。前端开发服务会自动更新。
使用单独新建的“删除流程测试”知识库，不删除已有学习资料。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 取消 | 点击行尾垃圾桶，检查名称，再取消或按 Esc | 知识库保留，数量不变，焦点返回删除入口 |
| 确认 | 再次打开并确认删除 | 弹窗关闭，记录消失，数量减一，有结果提示 |
| 数据一致 | 刷新页面，再通过侧栏进入概览 | 记录不再出现，概览数量与列表一致 |
| 小屏 | 窄窗口或手机尺寸打开表格/弹窗 | 编辑和删除按钮可用，弹窗不溢出 |
| 空列表 | 用新账号删除唯一一个测试知识库 | 显示空状态和 0 个知识库 |

分页回退、连续点击、503 重试、401 跳转、网络中断与 404 并发删除由浏览器测试覆盖；
不要求为了手工验收创建几十条记录或修改数据库。
开发者可阅读 delete-knowledge-base-dialog.tsx（交互与请求）、knowledge-base-table.tsx（刷新与分页）、
lib/api.ts（DELETE 和 204 响应处理）。实际删除权限仍由后端 routes/service 校验。
