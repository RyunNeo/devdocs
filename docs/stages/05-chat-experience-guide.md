# 会话体验模块使用指南

本轮实现：键盘发送、生成校验后展示、历史标签页、最近会话恢复和更早消息加载。
沿用现有0006数据库结构，无需新增迁移，也不需要重新上传或重新索引文档。
真实模型密钥和选型不变，没有额外开启深度思考或增加审核模型调用。

## 入口

打开 http://127.0.0.1:3001，进入知识库。
顶部有“文档 / 问答 / 历史会话”三个导航标签。
点击“问答”会恢复这个知识库最近一条非空会话。
点击“历史会话”可以选择旧会话继续提问，已有数据库记录会显示，不需要重新创建。
历史列表仅展示当前账号当前知识库，每页20条，标题来自第一条问题，摘要来自最近问题。

## 完整链路验收

| 操作 | 预期 |
| --- | --- |
| 输入问题，按Enter | 提交一次；发送按钮同样可用 |
| Shift+Enter | 在问题中换行，不提交 |
| 中文输入法选字时按Enter | 只确认输入，不误发送 |
| 提问后等待 | 显示检索、生成、校验阶段，不展示未验证草稿 |
| 回答完成 | 一次展示校验后的正文和引用，点击引用查看原文 |
| 文档依据不足 | 只展示中文依据不足提示，不显示内部英文标记或推测草稿 |
| 生成时停止 | 显示已停止，不展示或保存草稿，原问题仍保留 |
| 切到历史会话再打开原记录 | 恢复原会话ID，后续问题添加到原会话 |
| 从知识库再次进入问答 | 默认恢复最近一条非空会话 |
| 点击新会话再刷新 | 仍为空白新会话，不自动恢复旧记录；首次发送才创建 |
| 会话超过40条消息 | 可以加载更早消息，不重复、不漏页 |
| 同会话在另一标签页完成后继续提问 | 发问前同步已保存状态，旧答案不会冒充当前处理阶段 |

生成中页面内导航和新建会话会暂时禁用，可先停止再切换。
浏览器刷新/关闭可能中断当前请求；再次打开历史，读取服务端实际保存状态，不自动重发。
若另一页面仍在回答同一会话，本页会提示等待，不创建新的重复回答。

## 保存与费用

消息原本已保存在数据库，本轮补齐了可见入口和恢复能力。
失败、取消和未完成的assistant草稿不再通过详情或历史分页返回。
旧failed/cancelled数据不会被批量改写；旧completed答案也不会自动重新生成或重新验证。
新失败/取消记录保留状态和安全错误码，但正文与引用为空。
已经保存完成但浏览器未收到done时，可以从历史恢复；不要立即重复发送同一个问题。

等待完整生成会延长首段正文出现时间，处理状态和停止按钮用于反馈进展。
这不等于省掉已经生成的token；停止也不保证供应商不计费。
每轮依然最多一次问题Embedding和一次回答调用；恢复、历史标题和状态同步不调用模型。
引用编号校验不等于事实校验，仍应对照正确的知识库资料验收答案。

## 当前边界

历史记录暂不支持改名、删除或搜索，日志/用量/配额和部署仍需后续模块。
多标签页不做持续后台轮询；刷新或提交追问时同步最新状态。
旧completed错误答案不会被这次更新自动修改，建议新建会话测试新的资料与提示词。
无需更改.env；所有本轮自动化使用隔离数据库和假模型，真实问答由你主动发送。
