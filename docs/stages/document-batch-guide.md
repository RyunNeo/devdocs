# 文档批量操作验收指南

## 本次范围

支持一次选择最多 20 个 Markdown、TXT 或文本 PDF，每个文件仍不超过 10 MiB。
上传、索引、删除按文档逐个请求现有接口，不新增数据库表、迁移或模型配置。
原来的单文件操作保留。

## 操作与验收

1. 进入知识库的“文档”，一次选择多个文件，点击“上传文档”。
2. 检查每个文件的结果，以及成功、失败、跳过或停止的数量。成功上传但解析失败的文件已保存，应在文档行重新解析，不应再次上传。
3. 勾选文档，或使用表头复选框全选当前页；翻页、刷新列表后会清空选择。
4. 点击“批量建立索引”，核对文件和费用提示后确认。未成功解析或正在索引的文件会跳过。已完成的索引由后端检查是否可复用。
5. 点击“批量删除”，核对数量和文件名，确认后删除原文、片段与向量。取消弹窗不会删除。
6. 用手机宽度检查表格选择、批量工具栏、结果列表和确认弹窗。

## 失败与停止

- 某个文件的普通请求失败不会回滚已成功的文件，其他文件可继续处理。
- “重试失败项”仅重新上传明确失败的文件，不重复上传成功项，也不包含结果待确认或已停止的文件。
- 请求超时、网络中断或服务器异常会标记“结果待确认”，暂停后续任务。先刷新列表确认实际结果，再决定是否重新选择文件操作。
- 索引接口返回业务失败时也会暂停后续任务，避免密钥错误、模型限流等情况下继续调用服务。修复原因后重新选择未完成的文件。
- “停止后续上传/任务”不会中断当前文件，也不会撤销已完成操作。当前文件完成后，其余文件标记“已停止”。
- 登录失效会停止队列并跳转登录。

批次进度仅保留在当前页面，不是持久化后台任务。离开或刷新页面后，正在处理的服务端请求仍可能完成，应以刷新后的文档状态为准。
