# RAG 模块约定

| 文件 | 职责 | 阶段 |
| --- | --- | --- |
| loaders.py | MD/TXT 提取，PDF 页码保留，扫描 PDF 提示 | 2–3 |
| splitter.py | 清洗、代码块保留、标题/段落分块 | 3 |
| embeddings.py | 查询及批量文档向量接口 | 3–4 |
| retriever.py | 当前用户、知识库范围内检索 | 4 |
| prompts.py | 上下文模板、引用编号、资料非指令约束 | 4 |
| chain.py | 编排检索与流式生成 | 4 |

参考参数：800–1200 tokens/chunk，重叠 120–200 tokens，top_k=8。
需要选定 tokenizer；字符长度不等于 token 长度。
向量维度必须匹配模型实际输出，并在建表迁移中明确；更换模型需重新向量化。
小数据集先精确检索，是否添加 ANN 索引由数据规模和查询结果决定。
阈值必须通过样本校准，不直接把相似度当作回答正确率。
引用来自实际检索片段且支持对应结论，不能只将检索列表直接视为有效引用。
多轮追问需结合历史理解指代，必要时先改写为独立检索问题。

模型密钥与真实模型调用留在后端。本次不配置凭据或发起模型请求。
