# 模块 2.2 第三步：编辑弹窗

本轮只增加编辑，不推进删除或上传。沿用 PATCH /knowledge-bases/{id}，
无需新依赖、环境配置或数据库迁移。

## 先验收只改名称

1. 刷新 http://127.0.0.1:3001/knowledge-bases。
2. 找到 Python 练习，点击右侧铅笔图标。
3. 弹窗应填入现有名称和描述；没有修改时保存按钮禁用。
4. 只把名称改成 Python 项目练习，不动描述，点击保存。
5. 预期弹窗关闭，表格名称变化，描述和创建时间保留，总数不变。

把结果发给导师，我们确认这个行为后再检查清空描述和重名。

## 后续检查

- 清空描述并保存：描述显示短横线，后端保存 null。
- 只改描述：名称不变。
- 改成另一个知识库的同名名称：提示重名，保留弹窗中的输入。
- 所有空白和大小写差异不影响重名判定；只调整自己的展示空格仍可以保存。
- 点取消或 Esc：不发送修改，焦点回到行内编辑按钮。
- 保存中：防重复提交，暂时禁用关闭；失败后保留输入供重试。
- 保存成功：返回第 1 页刷新列表，更新记录按更新时间排在前面。

## 代码线索

创建与编辑共用 components/knowledge-bases/knowledge-base-dialog.tsx。
有 knowledgeBase 数据时是编辑，没有时是创建；同一份表单承担两种模式。
编辑对比原值后，仅把改动字段放入 PATCH 请求，避免发送未修改字段。
lib/api.ts 新增可选 HTTP 方法，旧的登录与创建调用保持原行为。
行内操作位于 knowledge-base-table.tsx，操作列在横向滚动时固定右侧。
