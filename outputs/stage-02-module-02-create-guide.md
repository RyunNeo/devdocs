# 模块 2.2 第二步：创建弹窗

你选择了弹窗形式。本轮只增加创建知识库，不推进编辑、删除或上传。
沿用已验收的 POST /knowledge-bases，无需新增配置、依赖或数据库迁移。

## 你先验收这一件事

1. 打开 http://127.0.0.1:3001/knowledge-bases，刷新页面。
2. 点击右上角“创建知识库”。
3. 名称填写 Python 学习，描述填写“我的 Python 与 AI 学习笔记”。
4. 点击创建，预期弹窗关闭、表格出现新记录。
5. 你的账号原先有 1 条记录，没有其他新增时，总数应变为 2。

先把是否创建成功、表格总数发给导师，再继续重名和取消练习。

## 之后可以检查

- 重名：再次创建 PYTHON 学习，弹窗显示已有同名提示，输入内容保留。
- 纠正：改成新名称后，可直接再次创建。
- 取消：输入名称后点取消或按 Esc，不创建记录，焦点回到创建按钮。
- 名称必填，首尾空格去掉后不能为空；最多 80 字符。
- 描述可不填，最多 1000 字符，空白描述保存为 null。
- 提交中按钮、输入和关闭操作暂时禁用，避免重复提交和误认为取消了保存。
- 如果提示无法确认结果，先关闭弹窗刷新列表核对，避免重复尝试。

## 本轮实现

原生 dialog 的模态展示使背景不可操作，并提供浏览器焦点约束。
创建成功后回到第 1 页重新读取列表，新记录按更新时间排序出现在前面。
401 跳转登录；重名及其他服务错误在弹窗中显示，不清空表单。
没有创建新的后端接口，后端仍是最终参数和权限检查的执行方。

核心文件现为 components/knowledge-bases/knowledge-base-dialog.tsx，创建和编辑复用。
表格中的创建按钮与成功刷新位于 knowledge-base-table.tsx。
